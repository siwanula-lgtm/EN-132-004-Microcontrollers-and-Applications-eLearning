รหัสวิชา: EN-132-004 ชื่อวิชา: Microcontrollers and Applications สัปดาห์ที่ 1

หน่วยที่: 1 ชื่อหน่วย:
โครงสร้างและหลักการทำงานของไมโครโพรเซสเซอร์และไมโครคอนโทรลเลอร์ จำนวน: 4 ชม.
(ท 2 / ป 2)

### สาระสําคัญ

ไมโครโพรเซสเซอร์ (Microprocessor)
คือหน่วยประมวลผลกลางที่ต้องอาศัยหน่วยความจำและอุปกรณ์ I/O
ภายนอกจึงจะทำงานเป็นระบบได้ ส่วนไมโครคอนโทรลเลอร์ (Microcontroller, MCU) รวม
CPU หน่วยความจำโปรแกรม (Flash) หน่วยความจำข้อมูล (SRAM) และอุปกรณ์รอบข้าง
(GPIO, ADC, Timer, UART ฯลฯ) ไว้ในชิปเดียว จึงเหมาะกับงานควบคุมแบบฝังตัว
(Embedded Control) การทำความเข้าใจระบบเลขฐานสอง/ฐานสิบหก โครงสร้างบัส วัฏจักร
Fetch–Decode–Execute และการกำหนดทิศทางพอร์ต I/O
เป็นพื้นฐานของการเขียนโปรแกรมควบคุมอุปกรณ์ในทุกหน่วยถัดไป

### เนื้อหาสาระ

1\. ระบบเลขฐานและการแปลงเลขฐาน

2\. โครงสร้างและสถาปัตยกรรมของไมโครโพรเซสเซอร์/ไมโครคอนโทรลเลอร์

3\. หน่วยความจำและการจัดการพอร์ต I/O

4\. ตระกูลไมโครคอนโทรลเลอร์ (AVR, ARM Cortex-M, ESP32)
และการจำลอง/พัฒนาโปรแกรม

### กิจกรรมการเรียนการสอน

### ขั้นนำเข้าสู่บทเรียน

1\. ผู้สอนแสดงอุปกรณ์ที่มีไมโครคอนโทรลเลอร์อยู่ภายใน เช่น เครื่องซักผ้า รีโมต
เครื่องวัดอุณหภูมิ และตั้งคำถาม 'อุปกรณ์เหล่านี้ทำงานตามโปรแกรมได้อย่างไร'

2\. ให้ผู้เรียนทำแบบทดสอบก่อนเรียนผ่าน QR Code (Google Forms)

3\. เชื่อมโยงคำตอบของผู้เรียนเข้าสู่หัวข้อไมโครโพรเซสเซอร์และไมโครคอนโทรลเลอร์

### ขั้นสอน/ประกอบกิจกรรม

1\. บรรยายระบบเลขฐานและฝึกแปลงเลขฐานร่วมกัน พร้อมแบบฝึกหัดสั้นในชั้นเรียน

2\. อธิบายโครงสร้างระบบคอมพิวเตอร์ บัส สถาปัตยกรรมภายใน CPU และวัฏจักร
Fetch–Decode–Execute ด้วยสื่อ PowerPoint

3\. เปรียบเทียบระบบ µP กับ µC และสถาปัตยกรรม Von Neumann กับ Harvard
โดยใช้แผนภาพ

4\. อธิบายหน่วยความจำและโครงสร้างพอร์ต I/O แล้วสาธิตการตั้งค่าขา GPIO ด้วย
MicroPython

5\. ผู้เรียนปฏิบัติใบงาน (2 ชั่วโมง) ต่อวงจร ESP32 + LED + ปุ่มกด + LDR และดูผลบน VS
Code Dashboard

### ขั้นสรุป

1\. สรุปสาระสำคัญร่วมกันโดยใช้แผนภาพโครงสร้าง CPU และพอร์ต I/O

2\. ให้ผู้เรียนส่งแบบสรุปผลการอภิปราย และทำแบบทดสอบหลังเรียนผ่าน QR Code

3\. เชื่อมโยงสู่หน่วยที่ 2 การเขียนโปรแกรมสำหรับไมโครคอนโทรลเลอร์ด้วย MicroPython
