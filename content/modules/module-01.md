- **1.3 เข้าใจชนิดของหน่วยความจำและหลักการจัดการพอร์ต I/O**

- **จุดประสงค์เชิงพฤติกรรม เมื่อเรียนจบหน่วยนี้แล้ว ผู้เรียนสามารถ**

## 1.1 ระบบควบคุมทางอิเล็กทรอนิกส์และระบบเลขฐาน

ระบบควบคุมทางอิเล็กทรอนิกส์ประกอบด้วยส่วนรับรู้ปริมาณทางกายภาพ (เซนเซอร์) ส่วนควบคุม
(คอนโทรลเลอร์) ภาคกำลัง และโหลด
สัญญาณจากเซนเซอร์จะถูกส่งเข้าสู่คอนโทรลเลอร์เพื่อเปรียบเทียบและตัดสินใจ
แล้วสั่งงานโหลดผ่านภาคกำลัง
ในปัจจุบันงานควบคุมส่วนใหญ่ใช้ไมโครคอนโทรลเลอร์เป็นคอนโทรลเลอร์
เพราะเปลี่ยนพฤติกรรมของระบบได้ด้วยโปรแกรมโดยแทบไม่ต้องแก้ไขวงจร

![ภาพที่ 1.1 ระบบควบคุมทางอิเล็กทรอนิกส์และทิศทางการไหลของสัญญาณ](/images/book/b04_image2.png)

ที่มา: ผู้จัดทำ (วาดใหม่โดยอ้างอิงแนวคิดจากเอกสารบรรยาย Week01 แนะนำระบบดิจิตอล
ไมโครโพรเซสเซอร์ และไมโครคอนโทรลเลอร์ ประจำรายวิชา)

สัญญาณอนาล็อกเปลี่ยนค่าได้ต่อเนื่องและไวต่อสัญญาณรบกวน
ส่วนสัญญาณดิจิทัลใช้เพียงสองระดับคือลอจิก 0 และลอจิก 1 จึงมีเสถียรภาพสูงกว่า สำหรับ ESP32
ที่ใช้แรงดัน 3.3 V ขาอินพุตจะอ่านเป็นลอจิก 1 เมื่อแรงดันไม่ต่ำกว่าประมาณ 0.75×VDD
และอ่านเป็นลอจิก 0 เมื่อไม่เกินประมาณ 0.25×VDD ตามที่ผู้ผลิตกำหนด

![ภาพที่ 1.2 เปรียบเทียบสัญญาณอนาล็อกและดิจิทัล พร้อมระดับลอจิกของ ESP32](/images/book/b04_image3.png)

ที่มา: ผู้จัดทำ (ระดับ VIH/VIL อ้างอิง Espressif Systems, ESP32 Series
Datasheet)

คอมพิวเตอร์ทุกชนิดเก็บและประมวลผลข้อมูลเป็นเลขฐานสอง (Binary) แต่ละหลักเรียกว่า 1 บิต
(bit) 8 บิตเรียกว่า 1 ไบต์ (Byte) และ 4 บิตเรียกว่า 1 นิบเบิล (Nibble)
ค่าของเลขฐานสองคำนวณจากค่าประจำหลัก 2ⁿ ของแต่ละบิต โดยบิตซ้ายสุดคือ MSB
และบิตขวาสุดคือ LSB ดังตัวอย่างในภาพที่ 1.3

![ภาพที่ 1.3 ค่าประจำหลักของเลขฐานสอง 8 บิต (ตัวอย่าง 10110110₂)](/images/book/b04_image4.png)

ที่มา: ผู้จัดทำ

การแปลงเลขฐานสิบเป็นฐานสองทำได้โดยหารสองซ้ำจนผลหารเป็นศูนย์ แล้วอ่านเศษจากล่างขึ้นบน
ดังภาพที่ 1.4 ซึ่งแปลง 45 เป็น 101101₂ ส่วนเลขฐานสิบหก (Hexadecimal) ใช้สัญลักษณ์
0–9 และ A–F แทนค่า 0–15 โดย 1 หลักฐานสิบหกแทน 4 บิตพอดี
จึงใช้ย่อเลขฐานสองให้อ่านง่าย เช่น 1011 0110₂ = B6₁₆

![ภาพที่ 1.4 การแปลงเลขฐานสิบเป็นเลขฐานสองด้วยการหารสองซ้ำ (ตัวอย่าง 45₁₀)](/images/book/b04_image5.png)

## 1.2 โครงสร้างและสถาปัตยกรรมของไมโครโพรเซสเซอร์/ไมโครคอนโทรลเลอร์

ระบบคอมพิวเตอร์ประกอบด้วย 4 หน่วยหลัก ได้แก่ หน่วยประมวลผลกลาง (CPU) หน่วยความจำ
(ROM/RAM) หน่วยรับข้อมูลเข้า (Input) และหน่วยส่งข้อมูลออก (Output)
หน่วยเหล่านี้สื่อสารกันผ่านบัส 3 ชนิด คือ Address Bus ที่ CPU
ใช้ระบุตำแหน่งของหน่วยความจำหรืออุปกรณ์ I/O (ทิศทางเดียว) Data Bus
ที่ส่งข้อมูลได้สองทิศทาง และ Control Bus ที่ส่งสัญญาณควบคุม เช่น สัญญาณอ่านและเขียน

![ภาพที่ 1.5 โครงสร้างระบบคอมพิวเตอร์และระบบบัส](/images/book/b04_image6.png)

ที่มา: ผู้จัดทำ (วาดใหม่โดยอ้างอิงแนวคิดจากเอกสารบรรยาย Week01 ประจำรายวิชา)

ภายใน CPU ประกอบด้วย Program Counter (PC) ที่ชี้ตำแหน่งคำสั่งถัดไป Instruction
Register (IR) ที่เก็บรหัสคำสั่งที่กำลังประมวลผล Instruction Decoder (ID)
ที่ถอดรหัสคำสั่ง Control Unit (CU) ที่สร้างสัญญาณควบคุม ALU
ที่คำนวณทางคณิตศาสตร์และลอจิก รีจิสเตอร์ทั่วไปและรีจิสเตอร์สถานะ (Flag) และ Stack
Pointer (SP) ที่ชี้ตำแหน่งของสแต็ก

![ภาพที่ 1.6 สถาปัตยกรรมภายในของไมโครโพรเซสเซอร์แบบย่อ](/images/book/b04_image7.png)

ที่มา: ผู้จัดทำ (วาดใหม่โดยอ้างอิงแนวคิดจากเอกสารบรรยาย Week01 ประจำรายวิชา)

การทำงานของ CPU เป็นวัฏจักรซ้ำ ๆ คือ Fetch (อ่านรหัสคำสั่งจากหน่วยความจำตามตำแหน่งที่
PC ชี้) Decode (ถอดรหัสคำสั่ง) Execute (ดำเนินการตามคำสั่ง) และปรับ PC
ให้ชี้คำสั่งถัดไป กระบวนการย่อยของแต่ละสภาวะเรียกว่า Machine Cycle

![ภาพที่ 1.7 วัฏจักร Fetch–Decode–Execute](/images/book/b04_image8.png)

ที่มา: ผู้จัดทำ

ระบบไมโครโพรเซสเซอร์ต้องต่อวงจรรวมภายนอกหลายตัว (ROM, RAM, IC อินพุต/เอาต์พุต)
ทำให้วงจรใหญ่และกินกำลังไฟมากกว่า แต่ยืดหยุ่นในการขยาย ส่วนไมโครคอนโทรลเลอร์รวม CPU
หน่วยความจำ และอุปกรณ์รอบข้างไว้ในชิปเดียว จึงลดขนาดวงจร ลดกำลังไฟ และลดต้นทุน
เหมาะกับงานควบคุมเฉพาะทาง เช่น เครื่องซักผ้า เครื่องวัดอุณหภูมิ และระบบอัตโนมัติในโรงงาน

![ภาพที่ 1.8 เปรียบเทียบระบบไมโครโพรเซสเซอร์หลายชิปกับไมโครคอนโทรลเลอร์ชิปเดียว](/images/book/b04_image9.png)

ตัวอย่างที่เป็น Harvard ได้แก่ไมโครคอนโทรลเลอร์ตระกูล AVR (เช่น ATmega328P)

## 1.3 หน่วยความจำและการจัดการพอร์ต I/O

หน่วยความจำในไมโครคอนโทรลเลอร์แบ่งหลัก ๆ เป็น Flash/ROM
เก็บโปรแกรมและไม่ลบเมื่อดับไฟ SRAM เก็บตัวแปรและสแต็กขณะทำงาน (ข้อมูลหายเมื่อดับไฟ)
และ EEPROM หรือพื้นที่เก็บค่าถาวร (เช่น NVS ใน ESP32) สำหรับค่าตั้งที่ต้องคงอยู่
แต่ละตำแหน่งมีแอดเดรสเฉพาะ และรีจิสเตอร์ของอุปกรณ์ I/O
มักถูกจัดไว้ในแผนที่หน่วยความจำเดียวกัน เรียกว่า Memory-Mapped I/O

![ภาพที่ 1.10 ชนิดของหน่วยความจำและแผนผังหน่วยความจำ (Memory Map)](/images/book/b04_image11.png)

ที่มา: ผู้จัดทำ

ขาพอร์ต I/O (GPIO) เป็นจุดเชื่อมต่อระหว่างไมโครคอนโทรลเลอร์กับโลกภายนอก
แต่ละขามีรีจิสเตอร์กำหนดทิศทาง (Direction) ว่าเป็นอินพุตหรือเอาต์พุต ถ้าเป็นเอาต์พุต
ค่าที่เขียนจะถูกเก็บใน Output Latch และขับออกที่ขา ถ้าเป็นอินพุต ตัว Input Buffer
จะอ่านระดับแรงดันที่ขาส่งไปยัง Data Bus ของ CPU ดังภาพที่ 1.11

![ภาพที่ 1.11 โครงสร้างพอร์ต I/O (GPIO) แบบง่าย](/images/book/b04_image12.png)

ที่มา: ผู้จัดทำ

ใน MicroPython กำหนดขาด้วยคลาส machine.Pin เช่น Pin(16, Pin.OUT) สำหรับขับ
LED และ Pin(4, Pin.IN, Pin.PULL_UP) สำหรับปุ่มกดที่ต่อลง GND เมื่อใช้ Pull-up
ภายใน ปุ่มที่ไม่ถูกกดจะอ่านได้ 1 และเมื่อกดจะอ่านได้ 0 สำหรับสัญญาณอนาล็อกใช้
machine.ADC ซึ่งใน ESP32 มีความละเอียด 12 บิต (0–4095) เมื่อกำหนดการลดทอน
ATTN_11DB ให้วัดแรงดันได้ราว 0–3.3 V (ผลการวัดจริงมีความไม่เป็นเชิงเส้นตามที่
Espressif ระบุ)

MHz พร้อม Wi-Fi และ Bluetooth ในชิปเดียว ซึ่งใช้เป็นบอร์ดมาตรฐานของรายวิชานี้
ตำราหลักของรายวิชา ได้แก่ Mazidi et al. (AVR) และ Zhu (ARM Cortex-M)

## บทสรุป

ไมโครโพรเซสเซอร์ (Microprocessor)
คือหน่วยประมวลผลกลางที่ต้องอาศัยหน่วยความจำและอุปกรณ์ I/O
ภายนอกจึงจะทำงานเป็นระบบได้ ส่วนไมโครคอนโทรลเลอร์ (Microcontroller, MCU) รวม
CPU หน่วยความจำโปรแกรม (Flash) หน่วยความจำข้อมูล (SRAM) และอุปกรณ์รอบข้าง
(GPIO, ADC, Timer, UART ฯลฯ) ไว้ในชิปเดียว จึงเหมาะกับงานควบคุมแบบฝังตัว
(Embedded Control) การทำความเข้าใจระบบเลขฐานสอง/ฐานสิบหก โครงสร้างบัส วัฏจักร
Fetch–Decode–Execute และการกำหนดทิศทางพอร์ต I/O
เป็นพื้นฐานของการเขียนโปรแกรมควบคุมอุปกรณ์ในทุกหน่วยถัดไป

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้ให้ถูกต้อง (10 ข้อ)

**1. จงแปลงเลขฐานสอง 1101 0110₂ เป็นเลขฐานสิบและฐานสิบหก**

<details><summary>เฉลย</summary>

128+64+16+4+2 = 214₁₀ ; แบ่งเป็น 1101 0110 = D 6 จึงได้ D6₁₆

</details>

**2. จงแปลงเลขฐานสิบ 200 เป็นเลขฐานสองและฐานสิบหก**

<details><summary>เฉลย</summary>

200 = 128+64+8 จึงได้ 1100 1000₂ = C8₁₆

</details>

**3. จงแปลง 0x3A เป็นเลขฐานสองและฐานสิบ**

<details><summary>เฉลย</summary>

3A₁₆ = 0011 1010₂ = 3×16+10 = 58₁₀

</details>

**4. ข้อมูล 8, 12 และ 16 บิต เก็บค่าจำนวนเต็มไม่มีเครื่องหมายได้ในช่วงใด**

<details><summary>เฉลย</summary>

8 บิต: 0–255 ; 12 บิต: 0–4095 ; 16 บิต: 0–65535 (สูตร 0 ถึง 2ⁿ−1)

</details>

**5. จงอธิบายหน้าที่ของ Address Bus, Data Bus และ Control Bus**

<details><summary>เฉลย</summary>

Address Bus ระบุตำแหน่งหน่วยความจำ/I-O (ทิศทางเดียวจาก CPU) ; Data Bus ส่งข้อมูลระหว่าง CPU กับหน่วยอื่น (สองทิศทาง) ; Control Bus ส่งสัญญาณควบคุม เช่น อ่าน/เขียน จัดจังหวะการทำงาน

</details>

**6. จงเปรียบเทียบระบบไมโครโพรเซสเซอร์กับระบบไมโครคอนโทรลเลอร์อย่างน้อย 3 ประเด็น**

<details><summary>เฉลย</summary>

(1) µP ต้องต่อ ROM/RAM/I-O ภายนอก ส่วน µC รวมไว้ในชิปเดียว (2) µC ใช้พื้นที่และกำลังไฟน้อยกว่า (3) µP เหมาะงานประมวลผลทั่วไปความเร็วสูง ส่วน µC เหมาะงานควบคุมเฉพาะทางและต้นทุนต่ำ

</details>

**7. จงอธิบายวัฏจักร Fetch–Decode–Execute และบทบาทของ Program Counter**

<details><summary>เฉลย</summary>

PC ชี้ตำแหน่งคำสั่ง → CPU อ่านคำสั่งเข้า IR (Fetch) → Instruction Decoder ถอดรหัส (Decode) → ALU/Control Unit ดำเนินการ (Execute) → PC เพิ่มค่าเพื่อชี้คำสั่งถัดไป แล้ววนซ้ำ

</details>

**8. จงเปรียบเทียบสถาปัตยกรรม Von Neumann กับ Harvard และบอกข้อดีของ Harvard 1 ข้อ**

<details><summary>เฉลย</summary>

Von Neumann ใช้หน่วยความจำ/บัสร่วมสำหรับคำสั่งและข้อมูล ส่วน Harvard แยกกัน ข้อดีของ Harvard คือเข้าถึงคำสั่งและข้อมูลพร้อมกันได้ ทำให้ประสิทธิภาพสูงขึ้น

</details>

**9. จงอธิบายความแตกต่างของ Flash, SRAM และ EEPROM ว่าเก็บอะไรและคงอยู่หลังดับไฟหรือไม่**

<details><summary>เฉลย</summary>

Flash เก็บโปรแกรมเฟิร์มแวร์ (คงอยู่) ; SRAM เก็บตัวแปร/สแต็กขณะทำงาน (หายเมื่อดับไฟ) ; EEPROM เก็บค่าตั้งที่ต้องคงอยู่ เขียนทับได้แต่จำนวนรอบจำกัด

</details>

**10. ADC 12 บิต อ้างอิง 3.3 V อ่านค่าดิบได้ 1024 แรงดันที่อ่านได้ประมาณเท่าใด (กรณีอุดมคติ)**

<details><summary>เฉลย</summary>

V = (1024/4095) × 3.3 ≈ 0.825 V

</details>
