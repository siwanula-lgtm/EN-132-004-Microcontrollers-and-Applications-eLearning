## 2.6 การเลื่อนและหมุนบิต (Shift/Rotate)

### สรุปท้ายใบความรู้

\- โปรแกรมประกอบด้วย import, กำหนดค่า, ฟังก์ชัน และลูปหลัก

\- ปุ่มกดแบบ Pull-up อ่านได้ 0 เมื่อกด ต้องดีบาวน์ก่อนนับ

\- ใช้ ticks_ms หรือ Timer แทน sleep เมื่อต้องตอบสนองหลายเหตุการณ์

\- Set = OR, Clear = AND ~mask, Toggle = XOR, Test = shift แล้ว AND 1

\- Shift คูณ/หาร 2 ส่วน Rotate หมุนบิตวนกลับ

\- if/elif/else เลือกโหมดการทำงานและเป็นพื้นฐานของ State Machine

## บทสรุป

โปรแกรมไมโครคอนโทรลเลอร์ด้วย MicroPython ประกอบด้วยส่วนนำเข้าโมดูล
การกำหนดค่าขา GPIO และ Timer การนิยามฟังก์ชัน และลูปหลักที่อ่านอินพุต ตัดสินใจ
และสั่งเอาต์พุตซ้ำ ๆ การทำงานกับบิตด้วยตัวดำเนินการ & \| ^ ~ \<\< \>\>
ทำให้ควบคุมกลุ่ม LED หรืออุปกรณ์หลายตัวได้อย่างมีประสิทธิภาพ ส่วน Timer และ Counter
ช่วยกำหนดเวลาและนับเหตุการณ์ได้โดยไม่ต้องหยุดโปรแกรมรอ
การจัดโปรแกรมเป็นฟังก์ชันและใช้โครงสร้าง if/elif/else ช่วยให้โปรแกรมอ่านง่าย
แก้ไขง่าย และพร้อมต่อยอดเป็นระบบควบคุมจริง

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้ให้ถูกต้อง (10 ข้อ)

**1. จงเขียนคำสั่งกำหนด GPIO19 เป็นเอาต์พุตและ GPIO5 เป็นอินพุตแบบ Pull-up ใน MicroPython**

<details><summary>เฉลย</summary>

led = Pin(19, Pin.OUT) ; sw = Pin(5, Pin.IN, Pin.PULL_UP) ; ต้อง from machine import Pin ก่อน

</details>

**2. ปุ่มต่อ GPIO4 ลง GND ใช้ Pull-up เมื่อกดอ่านได้ค่าใดและเมื่อไม่กดอ่านได้ค่าใด จงให้เหตุผล**

<details><summary>เฉลย</summary>

กด = 0 เพราะขาถูกต่อลง GND ; ไม่กด = 1 เพราะ Pull-up ดึงขึ้น 3.3 V

</details>

**3. จงอธิบายข้อดีของ ticks_ms เมื่อเทียบกับ sleep ในโปรแกรมที่ต้องอ่านปุ่มและกระพริบ LED พร้อมกัน**

<details><summary>เฉลย</summary>

ticks_ms ไม่หยุดโปรแกรม ลูปหลักจึงอ่านปุ่มได้ต่อเนื่องขณะตรวจว่าครบเวลากระพริบหรือไม่ ส่วน sleep ทำให้พลาดการกดปุ่มระหว่างรอ

</details>

**4. Timer(0).init(period=500, mode=Timer.PERIODIC, callback=f) เรียก f กี่ครั้งใน 10 วินาที และความถี่เท่าใด**

<details><summary>เฉลย</summary>

10 s ÷ 0.5 s = 20 ครั้ง ; ความถี่ f = 1/0.5 = 2 Hz

</details>

**5. กำหนด v = 0b00100100 จงหาผลของ v | 0x01, v & ~0x04 & 0xFF และ v ^ 0xFF**

<details><summary>เฉลย</summary>

v|0x01 = 00100101 ; v&~0x04 = 00100000 ; v^0xFF = 11011011

</details>

**6. จงเขียนนิพจน์ทดสอบบิต 6 ของ v และบอกค่าที่ได้เมื่อ v = 0x40**

<details><summary>เฉลย</summary>

(v >> 6) & 1 ; 0x40 = 01000000 บิต 6 = 1 จึงได้ 1

</details>

**7. จงเขียนฟังก์ชัน clamp(x, lo, hi) ที่ส่งค่ากลับ x แต่ไม่ต่ำกว่า lo และไม่เกิน hi**

<details><summary>เฉลย</summary>

def clamp(x, lo, hi):\n    if x < lo: return lo\n    if x > hi: return hi\n    return x

</details>

**8. คำนวณ 23 // 5, 23 % 5 และ 2 ** 5 พร้อมบอกการใช้ % ในโปรแกรมนับวน**

<details><summary>เฉลย</summary>

23//5 = 4 ; 23%5 = 3 ; 2**5 = 32 ; count % N ทำให้ค่าวนอยู่ในช่วง 0 ถึง N−1

</details>

**9. จงหา rol8(0b11000001) และ ror8(0b11000001)**

<details><summary>เฉลย</summary>

rol8: (10000010 | 00000001) = 10000011 ; ror8: (01100000 | 10000000) = 11100000

</details>

**10. จงเขียนโครงสร้าง if/elif/else เลือกโหมดตาม mode = 0,1,2 โดยโหมด 0 ติดทุกดวง (0xFF) โหมด 1 ดับทุกดวง (0x00) โหมด 2 กลับสถานะ**

<details><summary>เฉลย</summary>

if mode == 0: v = 0xFF ; elif mode == 1: v = 0x00 ; elif mode == 2: v = v ^ 0xFF ; else: pass

</details>
