## จุดประสงค์การสอน

- **5.1 อธิบายหลักการและข้อดีของ Interrupt เทียบกับการโพลลิ่งได้**
- **5.2 เขียน ISR สำหรับขาและ Timer ด้วย MicroPython ได้**
- **5.3 ตั้งค่าการสุ่ม ADC ด้วย Timer และปรับค่าดีบาวน์ได้**
- **จุดประสงค์เชิงพฤติกรรม เมื่อเรียนจบหน่วยนี้แล้ว ผู้เรียนสามารถ**
- **1) เปรียบเทียบการโพลลิ่งกับ Interrupt และยกตัวอย่างการใช้งานได้ (LLO6)**
- **2) เขียน Pin.irq พร้อมเลือกชนิด trigger ได้ถูกต้อง (LLO6)**
- **3) ระบุกฎของ ISR และแชร์ข้อมูลระหว่าง ISR กับลูปหลักได้ (LLO6)**
- **4) ตั้งคาบ Timer สุ่ม ADC และอธิบายผลของอัตราการสุ่มได้ (LLO6)**
- **5) ปรับเวลา Debounce และคำนวณความเร็วจากการนับพัลส์ได้ (LLO6)**

### สรุปท้ายใบความรู้

\- Interrupt ตอบสนองเหตุการณ์ทันทีและลดโอกาสพลาดเหตุการณ์

\- Timer ตั้งแฟล็กเพื่อสุ่ม ADC สม่ำเสมอ และต้องสุ่ม \> 2 เท่าของความถี่สัญญาณ

\- ISR ต้องสั้น ใช้แฟล็ก/ตัวนับ ไม่ใช้ print/หน่วงเวลา

\- Pin.irq เลือก FALLING/RISING ตามอุปกรณ์

\- ปรับดีบาวน์ให้เหมาะกับปุ่มหรือพัลส์เซนเซอร์

\- rpm = (พัลส์ ÷ PPR) × 60 ÷ T

## บทสรุป

Interrupt ทำให้ไมโครคอนโทรลเลอร์หยุดงานหลักชั่วคราวเพื่อตอบสนองเหตุการณ์ทันที เช่น
ขอบสัญญาณของขาหรือการครบเวลาของ Timer แล้วกลับไปทำงานหลักต่อ ฟังก์ชันบริการ (ISR)
ต้องสั้นมาก ใช้ตั้งแฟล็กหรือนับค่า แล้วให้ลูปหลักประมวลผลต่อ การตั้งค่าคาบ Timer สำหรับสุ่ม
ADC และเวลาดีบาวน์ต้องปรับแต่งให้เหมาะกับสัญญาณ เพื่อไม่พลาดเหตุการณ์และไม่นับซ้ำ

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้ให้ถูกต้อง (10 ข้อ)

**1. จงเปรียบเทียบ Polling กับ Interrupt อย่างน้อย 3 ประเด็น**

<details><summary>เฉลย</summary>

(1) Polling วนตรวจ Interrupt รอการแจ้ง (2) Polling อาจพลาดเหตุการณ์ (3) Interrupt ตอบสนองเร็วและประหยัด CPU แต่ต้องออกแบบ ISR ให้สั้นและระวังการแชร์ข้อมูล

</details>

**2. จงเขียนโค้ด Interrupt ขอบขาลงที่ GPIO4 ให้ตั้งแฟล็ก pressed = True**

<details><summary>เฉลย</summary>

btn = Pin(4, Pin.IN, Pin.PULL_UP) ; def cb(p): global pressed; pressed = True ; btn.irq(trigger=Pin.IRQ_FALLING, handler=cb)

</details>

**3. เหตุใดไม่ควรเรียก print ใน ISR**

<details><summary>เฉลย</summary>

เพราะใช้เวลานานและอาจจัดสรรหน่วยความจำ ทำให้ระบบตอบสนองเหตุการณ์อื่นช้าหรือเกิดข้อผิดพลาด ควรตั้งแฟล็กแล้ว print ในลูปหลัก

</details>

**4. Timer คาบ 20 ms มีอัตราสุ่มกี่ Hz และสุ่มสัญญาณสูงสุดกี่ Hz ได้โดยไม่เกิด Aliasing**

<details><summary>เฉลย</summary>

f = 1/0.02 = 50 Hz ; สัญญาณต้องต่ำกว่า 25 Hz

</details>

**5. จงอธิบาย Aliasing พร้อมยกตัวอย่าง**

<details><summary>เฉลย</summary>

การสุ่มช้าเกินไปทำให้เห็นสัญญาณเป็นความถี่ต่ำปลอม เช่น สัญญาณ 9 Hz สุ่มที่ 12 Hz

</details>

**6. นับพัลส์ได้ 300 ครั้งใน 3 วินาที PPR = 10 จงหา rpm**

<details><summary>เฉลย</summary>

รอบ = 300/10 = 30 รอบ ใน 3 s → 10 รอบ/s = 600 rpm

</details>

**7. ต้องการวัดความเร็วสูงสุด 3000 rpm จากเซนเซอร์ 20 PPR พัลส์จะมีความถี่กี่ Hz และดีบาวน์ควรไม่เกินกี่ ms**

<details><summary>เฉลย</summary>

f = 3000/60×20 = 1000 Hz → คาบ 1 ms ; ดีบาวน์ต้องน้อยกว่า 1 ms (ใช้ไมโครวินาทีเช่น 300–500 µs)

</details>

**8. จงเขียนเงื่อนไขดีบาวน์ใน ISR ด้วย ticks_us ให้ยอมรับเมื่อห่างกันเกิน 500 µs**

<details><summary>เฉลย</summary>

now = time.ticks_us ; if time.ticks_diff(now, last) > 500: cnt += 1 ; last = now

</details>

**9. ผู้เรียนกดปุ่มครั้งเดียวแต่ตัวนับเพิ่มเป็น 4 ควรแก้ไขอย่างไร**

<details><summary>เฉลย</summary>

เพิ่มเวลาดีบาวน์ (เช่น 50 ms) ตรวจ trigger เฉพาะ FALLING และตรวจต่อสายปุ่มให้ถูกต้อง

</details>

**10. จงอธิบายบทบาทของ micropython.schedule**

<details><summary>เฉลย</summary>

ให้ ISR ฝากงานให้ฟังก์ชันรันภายหลังนอกบริบทอินเทอร์รัปต์ เพื่อให้ทำงานที่ใช้เวลาหรือจัดสรรหน่วยความจำได้อย่างปลอดภัย

</details>
