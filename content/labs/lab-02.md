### 1. จุดประสงค์การทดลอง/การปฏิบัติงาน

1\. เพื่อให้ผู้เรียนต่อวงจรและเขียนโปรแกรม MicroPython อ่านปุ่มกดแบบ Pull-up
พร้อมดีบาวน์ได้

2\. เพื่อให้ผู้เรียนใช้ machine.Timer กำหนดคาบการเปลี่ยนลวดลายและใช้ฟังก์ชัน
rol8/ror8 ได้

3\. เพื่อให้ผู้เรียนใช้ Set/Clear/Toggle และ Shift/Rotate สร้างลวดลาย LED 4
โหมดได้

4\. เพื่อให้ผู้เรียนเห็นค่า MODE, SPEED, COUNT และค่าไบนารีของลวดลายบน Dashboard

### 2. รายการอุปกรณ์ (Bill of Materials - BOM)

1\. บอร์ด ESP32 Development Board (เช่น ESP32-DevKitC หรือเทียบเท่า) จำนวน 1
ชุด

2\. LED 5 mm จำนวน 8 ดวง และตัวต้านทาน 330 Ω จำนวน 8 ตัว

3\. ปุ่มกดแบบ Tactile Switch จำนวน 2 ตัว (ปุ่มโหมดและปุ่มความเร็ว)

4\. เบรดบอร์ด 1 แผ่น และสายจัมเปอร์ผู้-ผู้ 20–25 เส้น

5\. สาย Micro-USB หรือ USB-C สำหรับเชื่อมต่อ ESP32 กับคอมพิวเตอร์

6\. โปรแกรม Visual Studio Code พร้อมส่วนขยาย MicroPico และ Teleplot

7\. เฟิร์มแวร์ MicroPython ที่ติดตั้งลงในบอร์ด ESP32 เรียบร้อยแล้ว

### 3. แผนผังและขั้นตอนการต่อวงจร (Circuit Schematic & Wiring)

1\. ต่อ LED 8 ดวง โดยขาแอโนด (ขายาว) ผ่านตัวต้านทาน 330 Ω ไปยัง GPIO16, 17,
18, 19, 21, 22, 23, 25 ตามลำดับ (b0–b7) และต่อขาแคโทดลง GND

<p>from machine import Pin, Timer</p>
<p>import time</p>
<p>LED_PINS = (16, 17, 18, 19, 21, 22, 23, 25) # b0..b7 (b0 = LSB)</p>
<p>leds = [Pin(p, Pin.OUT) for p in LED_PINS]</p>
<p>btn_mode = Pin(4, Pin.IN, Pin.PULL_UP) # ปุ่มโหมด: กด = 0</p>
<p>btn_speed = Pin(5, Pin.IN, Pin.PULL_UP) # ปุ่มความเร็ว: กด = 0</p>
<p>SPEEDS = (500, 250, 125, 60) # คาบ Timer (ms)</p>
<p>def show(v):</p>
<p>"""เขียนค่า 8 บิตออกไปยัง LED"""</p>
<p>for i, led in enumerate(leds):</p>
<p>led.value((v &gt;&gt; i) &amp; 1)</p>
<p>def rol8(v): return ((v &lt;&lt; 1) | (v &gt;&gt; 7)) &amp; 0xFF #
หมุนซ้าย 1 บิต</p>
<p>def ror8(v): return ((v &gt;&gt; 1) | (v &lt;&lt; 7)) &amp; 0xFF #
หมุนขวา 1 บิต</p>
<p>tick = False</p>
<p>def on_tick(t): # callback ของ Timer: ตั้งแฟล็กเท่านั้น</p>
<p>global tick</p>
<p>tick = True</p>
<p>mode, sp, count, v = 0, 0, 0, 0x01</p>
<p>timer = Timer(0)</p>
<p>timer.init(period=SPEEDS[sp], mode=Timer.PERIODIC,
callback=on_tick)</p>
<p>last_m, last_s = 1, 1</p>
<p>t_m = t_s = time.ticks_ms</p>
<p>show(v)</p>
<p>while True:</p>
<p>m, s = btn_mode.value, btn_speed.value</p>
<p>now = time.ticks_ms</p>
<p>if last_m == 1 and m == 0 and time.ticks_diff(now, t_m) &gt; 200: #
ขอบขาลง + ดีบาวน์</p>
<p>mode = (mode + 1) % 4 # วนโหมด 0..3</p>
<p>v = 0x01 if mode &lt; 2 else 0x00</p>
<p>count += 1</p>
<p>t_m = now</p>
<p>if last_s == 1 and s == 0 and time.ticks_diff(now, t_s) &gt; 200:</p>
<p>sp = (sp + 1) % len(SPEEDS)</p>
<p>timer.init(period=SPEEDS[sp], mode=Timer.PERIODIC,
callback=on_tick)</p>
<p>t_s = now</p>
<p>last_m, last_s = m, s</p>
<p>if tick:</p>
<p>tick = False</p>
<p>if mode == 0: v = rol8(v) # แสงวิ่งซ้าย</p>
<p>elif mode == 1: v = ror8(v) # แสงวิ่งขวา</p>
<p>elif mode == 2: v = v ^ 0xFF # กระพริบทุกดวง (Toggle)</p>
<p>else: # แถบไฟเติมจากขวา</p>
<p>v = ((v &lt;&lt; 1) | 1) &amp; 0xFF</p>
<p>if v == 0xFF: v = 0</p>
<p>show(v)</p>
<p>print("&gt;MODE:{}".format(mode));
print("&gt;SPEED_MS:{}".format(SPEEDS[sp]))</p>
<p>print("&gt;COUNT:{}".format(count))</p>
<p>print("mode={} speed={}ms count={} v=0b{:08b}
hex=0x{:02X}".format(mode, SPEEDS[sp], count, v, v))</p>

### 5. ขั้นตอนการตั้งค่า Dashboard บน VS Code

1\. เปิดโปรแกรม Visual Studio Code แล้วติดตั้งส่วนขยาย 'MicroPico' (หรือ
'Pymakr') และ 'Teleplot' จาก Extensions Marketplace

2\. เชื่อมต่อ ESP32 กับคอมพิวเตอร์ด้วยสาย USB แล้วเลือกพอร์ต (COM Port) ที่ถูกต้อง

3\. สร้างโฟลเดอร์โครงงาน สร้างไฟล์ main.py วางโค้ดตามข้อ 4 แล้วกด Upload/Run
ไปยังบอร์ด

SPEED_MS และ COUNT

5\. กดปุ่มโหมดทีละครั้ง สังเกตลวดลาย LED ทั้ง 4 โหมดและบันทึกค่า v ที่เห็นในตารางที่ 2.2

### ส่วนที่ 2 เกณฑ์ประเมินพุทธิพิสัย (Cognitive Domain)

ใช้เกณฑ์ Marking scheme ตาม มคอ.3 (ข้อละ 10 คะแนนดิบ): การอ่านโจทย์
Given/Determine = 1, การกำหนด Assumption/เขียน system = 2, การ Analysis
ระบุสมการ = 1, กระบวนการแก้สมการ = 5, ผลเฉลย = 1

### ส่วนที่ 3 เกณฑ์ประเมินทักษะพิสัย (Psychomotor Domain)

ใช้แบบประเมินทักษะการปฏิบัติงานของใบงานที่ 2 (5 หัวข้อ × 4 ระดับ รวม 20 คะแนน: 4 =
ดีมาก, 3 = ดี, 2 = พอใช้, 1 = ปรับปรุง)

### ส่วนที่ 4 เกณฑ์ประเมินจิตพิสัย (Affective Domain) คะแนนเต็ม 20 คะแนน

ประเมินโดยผู้สอนตลอดหน่วยการเรียน

| **หัวข้อการประเมิน**          | **5 (ดีมาก)**                      | **4 (ดี)**           | **3 (พอใช้)**       | **2 (ควรปรับปรุง)**     | **1 (ต้องแก้ไข)**     |

| 2\. ความรับผิดชอบต่อหน้าที่      | ทำหน้าที่ครบถ้วนโดยไม่ต้องกำกับ          | ทำครบ ต้องเตือนเล็กน้อย | ทำบางส่วน           | ต้องกำกับตลอด           | ไม่ทำหน้าที่            |
