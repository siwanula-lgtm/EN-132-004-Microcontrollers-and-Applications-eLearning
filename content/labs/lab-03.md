### 1. จุดประสงค์การทดลอง/การปฏิบัติงาน

1\. เพื่อให้ผู้เรียนต่อวงจรขับมอเตอร์ DC (L298N หรือ TB6612FNG) กับ ESP32
ได้อย่างถูกต้องและปลอดภัย

2\. เพื่อให้ผู้เรียนเขียนโปรแกรม State Machine 4 สถานะ (STOP, FWD, STOP, REV)
ได้

3\. เพื่อให้ผู้เรียนปรับความเร็วด้วย PWM จากค่า ADC ของ potentiometer พร้อม Soft
start ได้

4\. เพื่อให้ผู้เรียนคำนวณแรงดันเฉลี่ยและกำลังโดยประมาณและเปรียบเทียบกับค่าที่วัดได้

### 2. รายการอุปกรณ์ (Bill of Materials - BOM)

1\. บอร์ด ESP32 Development Board จำนวน 1 ชุด

2\. โมดูลขับมอเตอร์ L298N (หรือ TB6612FNG) จำนวน 1 ชุด

3\. มอเตอร์ DC แบบมีเกียร์ 6–12 V จำนวน 1 ตัว และแบตเตอรี่/แหล่งจ่าย 6–9 V

4\. Potentiometer 10 kΩ 1 ตัว และปุ่มกด Tactile 1 ตัว

5\. เบรดบอร์ด สายจัมเปอร์ และมัลติมิเตอร์สำหรับวัดแรงดัน/กระแส

6\. สาย USB, โปรแกรม Visual Studio Code พร้อมส่วนขยาย MicroPico และ
Teleplot

7\. เฟิร์มแวร์ MicroPython ที่ติดตั้งในบอร์ด ESP32 เรียบร้อยแล้ว

### 3. แผนผังและขั้นตอนการต่อวงจร (Circuit Schematic & Wiring)

1\. ถอดจัมเปอร์ ENA บนโมดูล L298N ออก แล้วต่อ ENA เข้ากับ GPIO25 (PWM) IN1
เข้ากับ GPIO26 และ IN2 เข้ากับ GPIO27

2\. ต่อมอเตอร์เข้ากับ OUT1 และ OUT2 ต่อแหล่งจ่ายมอเตอร์ 6–9 V เข้าขั้ว +12V/VS
และต่อ GND ของแหล่งจ่ายเข้ากับ GND ของโมดูลและ GND ของ ESP32 ร่วมกัน

3\. ต่อ Potentiometer ปลายทั้งสองเข้า 3V3 และ GND ขากลางเข้า GPIO34
และต่อปุ่มกดระหว่าง GPIO4 กับ GND (Pull-up ภายใน)

4\. ให้ผู้สอนตรวจการต่อสายก่อนจ่ายไฟทุกครั้ง ห้ามจ่ายไฟมอเตอร์เกินพิกัดของมอเตอร์

<p>from machine import Pin, PWM, ADC</p>
<p>import time</p>
<p>in1 = Pin(26, Pin.OUT); in2 = Pin(27, Pin.OUT)</p>
<p>ena = PWM(Pin(25), freq=1000); ena.duty_u16(0) # PWM 1 kHz</p>

<p>RAMP = 1500 # ก้าวเพิ่มดิวตี้ต่อ 20 ms (Soft start)</p>
<p>NAMES = ('STOP', 'FWD', 'STOP2', 'REV')</p>
<p>state, pending, duty = 0, None, 0</p>
<p>last_btn, t_btn, t_pr = 1, time.ticks_ms, time.ticks_ms</p>
<p>while True:</p>
<p>b = btn.value; now = time.ticks_ms</p>
<p>if last_btn == 1 and b == 0 and time.ticks_diff(now, t_btn) &gt; 200
and pending is None:</p>
<p>pending = (state + 1) % 4 # ขอเปลี่ยนสถานะ</p>
<p>t_btn = now</p>
<p>last_btn = b</p>
<p>target = pot.read * 16 if state in (1, 3) else 0 # 0..65520</p>
<p>if pending is not None: target = 0 # ลดดิวตี้เป็น 0 ก่อนเปลี่ยนทิศ</p>
<p>if duty &lt; target: duty = min(duty + RAMP, target)</p>
<p>elif duty &gt; target: duty = max(duty - RAMP, target)</p>
<p>ena.duty_u16(duty)</p>
<p>if pending is not None and duty == 0: # เปลี่ยนทิศเมื่อหยุดสนิท</p>
<p>state, pending = pending, None</p>
<p>if state == 1: in1.value(1); in2.value(0)</p>
<p>elif state == 3: in1.value(0); in2.value(1)</p>
<p>else: in1.value(0); in2.value(0)</p>
<p>if time.ticks_diff(now, t_pr) &gt;= 200:</p>
<p>pct = duty * 100 / 65535</p>
<p>vavg = VS * pct / 100</p>
<p>print("&gt;DUTY_PCT:{:.1f}".format(pct));
print("&gt;V_AVG:{:.2f}".format(vavg))</p>
<p>print("&gt;P_EST_W:{:.2f}".format(vavg * I_NOM));
print("&gt;STATE:{}".format(state))</p>
<p>print("state={} duty={:.1f}% Vavg={:.2f}V
P~{:.2f}W".format(NAMES[state], pct, vavg, vavg * I_NOM))</p>
<p>t_pr = now</p>
<p>time.sleep_ms(20)</p></th>
