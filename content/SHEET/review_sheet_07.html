📌 1. สาระสำคัญ

เซนเซอร์และอุปกรณ์ในระบบฝังตัวสื่อสารด้วยโปรโตคอลที่ต่างกัน 1-Wire ใช้สายข้อมูลเดียวและรหัส ROM 64 บิต Modbus RTU เป็นโปรโตคอลมาสเตอร์/สเลฟที่นิยมในอุตสาหกรรมและตรวจข้อมูลด้วย CRC-16 จอ LCD/OLED แสดงค่าบนอุปกรณ์ ส่วน Keypad 4x4 ใช้การสแกนแถว-คอลัมน์ ก่อนเปิดระบบต้องตรวจการเดินสายและใช้เครื่องมือวัดเพื่อหาสาเหตุเมื่อสื่อสารไม่ได้

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 7.1 อธิบายโปรโตคอล 1-Wire และ Modbus RTU ได้
  • 7.2 ใช้เครื่องมือตรวจสอบสัญญาณวัดและการสื่อสารได้
  • 7.3 เขียนโปรแกรมแสดงผลบน OLED และอ่าน Keypad ได้
  • 7.4 ตรวจสอบการเดินสายและอินพุต/เอาต์พุตก่อนใช้งานได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 7.1 โปรโตคอลที่ใช้กับเซนเซอร์
  • 7.2 เครื่องมือตรวจสอบสัญญาณการวัดและการสื่อสาร
  • 7.3 การแสดงผลด้วย LCD และ OLED
  • 7.4 การอ่านปุ่มกดแบบเมทริกซ์ Keypad
  • 7.5 การตรวจสอบการเดินสายและอินพุต/เอาต์พุต
📝 4. บทสรุป

เซนเซอร์และอุปกรณ์ในระบบฝังตัวสื่อสารด้วยโปรโตคอลที่ต่างกัน 1-Wire ใช้สายข้อมูลเดียวและรหัส ROM 64 บิต Modbus RTU เป็นโปรโตคอลมาสเตอร์/สเลฟที่นิยมในอุตสาหกรรมและตรวจข้อมูลด้วย CRC-16 จอ LCD/OLED แสดงค่าบนอุปกรณ์ ส่วน Keypad 4x4 ใช้การสแกนแถว-คอลัมน์ ก่อนเปิดระบบต้องตรวจการเดินสายและใช้เครื่องมือวัดเพื่อหาสาเหตุเมื่อสื่อสารไม่ได้

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงคำนวณอุณหภูมิจากค่าดิบ DS18B20 12 บิต 0x0140
  • DS18B20 ความละเอียด 11 บิต มีขั้นกี่องศาและใช้เวลาแปลงเท่าใด
  • เหตุใดสาย 1-Wire ต้องมีตัวต้านทานพูลอัพ
  • จงอธิบายแต่ละฟิลด์ของเฟรม 01 03 00 00 00 02 C4 0B
  • ที่ 19200 8N1 เฟรม Modbus 8 ไบต์ใช้เวลาเท่าใด
  • ควรเลือกเครื่องมือใดเมื่อ I2C สแกนไม่พบอุปกรณ์ และเพราะเหตุใด
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 7

อ่านอุณหภูมิ DS18B20 (1-Wire) แสดงผลบน OLED และรับรหัส PIN จาก Keypad 4x4 พร้อมส่งข้อมูลขึ้น VS Code Dashboard
