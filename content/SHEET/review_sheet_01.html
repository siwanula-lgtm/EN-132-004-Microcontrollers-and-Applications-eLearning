📌 1. สาระสำคัญ

ไมโครโพรเซสเซอร์ (Microprocessor) คือหน่วยประมวลผลกลางที่ต้องอาศัยหน่วยความจำและอุปกรณ์ I/O ภายนอกจึงจะทำงานเป็นระบบได้ ส่วนไมโครคอนโทรลเลอร์ (Microcontroller, MCU) รวม CPU หน่วยความจำโปรแกรม (Flash) หน่วยความจำข้อมูล (SRAM) และอุปกรณ์รอบข้าง (GPIO, ADC, Timer, UART ฯลฯ) ไว้ในชิปเดียว จึงเหมาะกับงานควบคุมแบบฝังตัว (Embedded Control) การทำความเข้าใจระบบเลขฐานสอง/ฐานสิบหก โครงสร้างบัส วัฏจักร Fetch–Decode–Execute และการกำหนดทิศทางพอร์ต I/O เป็นพื้นฐานของการเขียนโปรแกรมควบคุมอุปกรณ์ในทุกหน่วยถัดไป

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 1.1 เข้าใจระบบเลขฐาน 2, 8, 10, 16 และสามารถแปลงเลขฐานได้
  • 1.2 อธิบายโครงสร้างและหลักการทำงานของไมโครโพรเซสเซอร์และไมโครคอนโทรลเลอร์ได้
  • 1.3 เข้าใจชนิดของหน่วยความจำและหลักการจัดการพอร์ต I/O
  • 1.4 สามารถต่อวงจรและเขียนโปรแกรม MicroPython เบื้องต้นบน ESP32 เพื่ออ่าน/เขียนขา GPIO และ ADC ได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 1.1 ระบบควบคุมทางอิเล็กทรอนิกส์และระบบเลขฐาน
  • 1.2 โครงสร้างและสถาปัตยกรรมของไมโครโพรเซสเซอร์/ไมโครคอนโทรลเลอร์
  • 1.3 หน่วยความจำและการจัดการพอร์ต I/O
  • 1.4 ตระกูลไมโครคอนโทรลเลอร์และการพัฒนาโปรแกรม
📝 4. บทสรุป

ไมโครโพรเซสเซอร์ (Microprocessor) คือหน่วยประมวลผลกลางที่ต้องอาศัยหน่วยความจำและอุปกรณ์ I/O ภายนอกจึงจะทำงานเป็นระบบได้ ส่วนไมโครคอนโทรลเลอร์ (Microcontroller, MCU) รวม CPU หน่วยความจำโปรแกรม (Flash) หน่วยความจำข้อมูล (SRAM) และอุปกรณ์รอบข้าง (GPIO, ADC, Timer, UART ฯลฯ) ไว้ในชิปเดียว จึงเหมาะกับงานควบคุมแบบฝังตัว (Embedded Control) การทำความเข้าใจระบบเลขฐานสอง/ฐานสิบหก โครงสร้างบัส วัฏจักร Fetch–Decode–Execute และการกำหนดทิศทางพอร์ต I/O เป็นพื้นฐานของการเขียนโปรแกรมควบคุมอุปกรณ์ในทุกหน่วยถัดไป

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงแปลงเลขฐานสอง 1101 0110₂ เป็นเลขฐานสิบและฐานสิบหก
  • จงแปลงเลขฐานสิบ 200 เป็นเลขฐานสองและฐานสิบหก
  • จงแปลง 0x3A เป็นเลขฐานสองและฐานสิบ
  • ข้อมูล 8, 12 และ 16 บิต เก็บค่าจำนวนเต็มไม่มีเครื่องหมายได้ในช่วงใด
  • จงอธิบายหน้าที่ของ Address Bus, Data Bus และ Control Bus
  • จงเปรียบเทียบระบบไมโครโพรเซสเซอร์กับระบบไมโครคอนโทรลเลอร์อย่างน้อย 3 ประเด็น
