📌 1. สาระสำคัญ

Interrupt ทำให้ไมโครคอนโทรลเลอร์หยุดงานหลักชั่วคราวเพื่อตอบสนองเหตุการณ์ทันที เช่น ขอบสัญญาณของขาหรือการครบเวลาของ Timer แล้วกลับไปทำงานหลักต่อ ฟังก์ชันบริการ (ISR) ต้องสั้นมาก ใช้ตั้งแฟล็กหรือนับค่า แล้วให้ลูปหลักประมวลผลต่อ การตั้งค่าคาบ Timer สำหรับสุ่ม ADC และเวลาดีบาวน์ต้องปรับแต่งให้เหมาะกับสัญญาณ เพื่อไม่พลาดเหตุการณ์และไม่นับซ้ำ

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 5.1 อธิบายหลักการและข้อดีของ Interrupt เทียบกับการโพลลิ่งได้
  • 5.2 เขียน ISR สำหรับขาและ Timer ด้วย MicroPython ได้
  • 5.3 ตั้งค่าการสุ่ม ADC ด้วย Timer และปรับค่าดีบาวน์ได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 5.1 การตั้งค่าพารามิเตอร์ ADC และ Timer
  • 5.2 ชนิดของ Interrupt และการจัดลำดับความสำคัญ
  • 5.3 การทดสอบและปรับแต่งพารามิเตอร์ (Debounce/ช่วงเวลา Timer)
📝 4. บทสรุป

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงเปรียบเทียบ Polling กับ Interrupt อย่างน้อย 3 ประเด็น
  • จงเขียนโค้ด Interrupt ขอบขาลงที่ GPIO4 ให้ตั้งแฟล็ก pressed = True
  • เหตุใดไม่ควรเรียก print ใน ISR
  • Timer คาบ 20 ms มีอัตราสุ่มกี่ Hz และสุ่มสัญญาณสูงสุดกี่ Hz ได้โดยไม่เกิด Aliasing
  • จงอธิบาย Aliasing พร้อมยกตัวอย่าง
  • นับพัลส์ได้ 300 ครั้งใน 3 วินาที PPR = 10 จงหา rpm
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 5

นับพัลส์ด้วย Interrupt พร้อมดีบาวน์ สุ่ม ADC ด้วย Timer และแสดงความเร็วรอบบน VS Code Dashboard
