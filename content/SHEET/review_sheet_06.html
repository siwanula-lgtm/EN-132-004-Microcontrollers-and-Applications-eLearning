📌 1. สาระสำคัญ

การสื่อสารแบบอนุกรมช่วยให้ไมโครคอนโทรลเลอร์แลกเปลี่ยนข้อมูลกับคอมพิวเตอร์ โมดูล และเซนเซอร์โดยใช้สายน้อย UART เป็นแบบอะซิงโครนัสที่ต้องตั้งค่าบอดเรตและรูปแบบเฟรมให้ตรงกัน ส่วน I2C ใช้สองสายและแอดเดรสเลือกอุปกรณ์ และ SPI ใช้สัญญาณนาฬิกากับขา CS ให้ความเร็วสูง หน้าจอ HMI ที่ดีแสดงสถานะ ค่ากระบวนการ การสั่งงานและสัญญาณเตือนอย่างชัดเจน การรวมการสื่อสารกับเซนเซอร์และแอคชูเอเตอร์ เช่น เซอร์โวและสายพาน ต้องออกแบบเครื่องสถานะและการจัดการข้อผิดพลาด

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 6.1 อธิบายหลักการและเขียนโปรแกรมสื่อสาร UART ได้
  • 6.2 เปรียบเทียบและใช้งาน I2C และ SPI ได้
  • 6.3 ออกแบบหน้าจอ HMI และโปรโตคอลคำสั่งอย่างง่ายได้
  • 6.4 ประยุกต์การสื่อสารกับเซนเซอร์และเซอร์โวในระบบอัตโนมัติได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 6.1 หลักการสื่อสารแบบ UART/USART
  • 6.2 การออกแบบหน้าจอ HMI สำหรับแสดงผลและควบคุม
  • 6.3 การสื่อสาร SPI และ I2C
  • 6.4 การเชื่อมต่อไมโครคอนโทรลเลอร์กับอุปกรณ์ภายนอก
  • 6.5 การควบคุมแขนกลและสายพานลำเลียงด้วยไมโครคอนโทรลเลอร์
  • 6.6 การประยุกต์ใช้ไมโครคอนโทรลเลอร์ควบคุมระบบเมคคาทรอนิกส์
  • 6.7 การออกแบบโปรแกรมควบคุมระบบอัตโนมัติ
📝 4. บทสรุป

การสื่อสารแบบอนุกรมช่วยให้ไมโครคอนโทรลเลอร์แลกเปลี่ยนข้อมูลกับคอมพิวเตอร์ โมดูล และเซนเซอร์โดยใช้สายน้อย UART เป็นแบบอะซิงโครนัสที่ต้องตั้งค่าบอดเรตและรูปแบบเฟรมให้ตรงกัน ส่วน I2C ใช้สองสายและแอดเดรสเลือกอุปกรณ์ และ SPI ใช้สัญญาณนาฬิกากับขา CS ให้ความเร็วสูง หน้าจอ HMI ที่ดีแสดงสถานะ ค่ากระบวนการ การสั่งงานและสัญญาณเตือนอย่างชัดเจน การรวมการสื่อสารกับเซนเซอร์และแอคชูเอเตอร์ เช่น เซอร์โวและสายพาน ต้องออกแบบเครื่องสถานะและการจัดการข้อผิดพลาด

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงคำนวณเวลาที่ใช้ส่งข้อความ "HELLOn" (6 ไบต์) ที่ 9600 bit/s รูปแบบ 8N1
  • จงอธิบายความหมายของ UART 115200 8N1
  • จงวาดเฟรม UART ของอักขระ A (0x41) โดยเรียงบิตจากซ้ายไปขวา
  • จงเปรียบเทียบ I2C กับ SPI อย่างน้อย 3 ประเด็น
  • สแกน I2C พบ [0x3C, 0x44] จงคาดคะเนอุปกรณ์ที่ต่ออยู่
  • ค่าดิบความชื้น 0x8000 = 32768 จาก SHT30 คิดเป็น RH กี่เปอร์เซ็นต์
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 6

HMI ผ่านพอร์ตอนุกรม: อ่าน SHT30 ด้วย I2C ควบคุมเซอร์โวและ LED ด้วยคำสั่ง ASCII และทดสอบ UART loopback แสดงผลบน VS Code Dashboard
